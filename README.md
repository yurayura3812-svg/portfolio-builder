## 直近でぶつかった壁と解決セーブデータ

### 1. ネットワーク経由でボタンや入力が反応しない問題
- **現象**: ローカル環境（`localhost:3000`）では正常に動くものの、Wi-Fi経由（IPアドレス指定）でアクセスすると、HTMLの見た目だけが表示され、ボタンのクリックや入力の連動（JavaScriptの処理）が一切機能しない「静的サイト状態」になった。
- **原因**: Next.js の開発環境におけるセキュリティ強化機能（Fast Refreshのクロスオリジンブロック）により、異なるオリジンからのHMR（Hot Jam/WebSocket）通信が安全のために強制遮断されていたため。
- **解決策**: `next.config.ts` に `allowedDevOrigins` を設定し、該当のIPアドレスからの通信を明示的に許可することで、JavaScriptの正常なドッキング（Hydration）を確認。
