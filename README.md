## 直近でぶつかった壁と解決セーブデータ

### 1. ネットワーク経由でボタンや入力が反応しない問題
- **現象**: ローカル環境（`localhost:3000`）では正常に動くものの、Wi-Fi経由（IPアドレス指定）でアクセスすると、HTMLの見た目だけが表示され、ボタンのクリックや入力の連動（JavaScriptの処理）が一切機能しない「静的サイト状態」になった。
- **原因**: Next.js の開発環境におけるセキュリティ強化機能（Fast Refreshのクロスオリジンブロック）により、異なるオリジンからのHMR（Hot Jam/WebSocket）通信が安全のために強制遮断されていたため。
- **解決策**: `next.config.ts` に `allowedDevOrigins` を設定し、該当のIPアドレスからの通信を明示的に許可することで、JavaScriptの正常なドッキング（Hydration）を確認。
### 2. 静的エクスポート（SSG）展開時のCSS剥がれ問題
- **現象**: `output: 'export'` を設定して `npm run build` を実行し、生成された `out/share.html` をブラウザで直接ダブルクリック（ファイルモード：`file://`）で開いたところ、Tailwind CSSのデザインが一切適用されず、真っ白な背景に黒文字の質素な画面になってしまった。
- **原因**: Next.jsが書き出した各種アセット（CSS/JS）の絶対パス・相対パスの解決ルールが、ローカルのファイルシステム直接参照に対応していない（Webサーバー経由での配信を前提としている）ため、ブラウザがスタイルシートを見失っていた。
- **解決策**: ローカル環境に軽量Webサーバー（`npx serve`）を立ち上げ、`http://localhost:5000/share` 経由で本物のWebホスティングに近い環境でアクセスしたところ、Tailwind CSSのデザインが100%完璧に適用されることを確認。
